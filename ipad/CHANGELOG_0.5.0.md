# 0.5.0

- Ported v24 geometry objects and rendering.
- Added line, arrow, curve, rectangle, square, ellipse, circle, triangle and diamond creation.
- Added configurable X-Y planes and axis snapping.
- Added lasso selection for ink and geometry.
- Added move, uniform scale, rotation and line/curve point handles.
- Added copy, paste and delete for selections.
- Added locking and unlocking for ink and geometry.
- Added v24-style hold recognition for lines and quadratic curves.
- Added endpoint, axis, tangent and normal snapping.
- Consolidated settings under a pinned vertical three-dot button.
- Split settings into Connection, Display, Stroke, Geometry, Selection and Diagnostics tabs.
- Retained the 0.4.3 vector PDF renderer and zoom-independent live stroke performance fixes.
